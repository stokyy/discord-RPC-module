# discord-RPC-module

Эта программа отслеживает активные окна Windows и отображает информацию о них в Discord через систему Rich Presence (RPC). Основные возможности:

Отслеживание активных приложений:

1. Автоматически определяет какое приложение сейчас активно;
2. Показывает название процесса, например, *chrome* (да-да, без .exe);
3. Определяет PID процесса.

Discord Integration:
1. Отображает статус в профиле Discord;
2. Показывает иконки приложений;
3. Отображает дополнительную информацию, которую вы сами и напишите в cfg, при наведении.

Системный трей:

1. Работает в фоновом режиме;
2. Позволяет управлять программой через иконку в трее;
3. Есть опции скрытия/показа консоли.

Уведомления:

1. Показывает всплывающие уведомления в Windows (only win 11);
2. Оповещает о запуске/остановке программы.

Как это работает?
1. Программа каждые N секунд (указывается в конфиге) проверяет какое окно активно;
2. Для активного окна определяется процесс и его название;
3. На основе названия процесса ищется соответствующая конфигурация в config.json;
4. Если конфигурация найдена - обновляется статус в Discord;
5. Если не найдена - используется статус по умолчанию (прописано в коде - 72я строчка. используется для process_name`ов, которых нет в cfg).

Файл config.json нужен для настройки программы:

Основные настройки:

{
    "application_id": "00000000000000000",
    "debug_mode": false,
    "time": 1,
    "trey": false,
    "applications": {
        "process_name": {"custom_name": "ur_custom_process_name", "text": "ur_custom_text", "image": "ur_custom_img", "small_image": "ur_custom_small_img", "tooltip": "ur_custom_big_img_text", "small_text": "ur_custom_small_img_text"}
    }
}

1. application_id - ID вашей апликации Discord;
2. debug_mode - включение режима отладки (вывод в консоль);
3. time - интервал обновления статуса в секундах;
4. trey - показывать ли иконку в системном трее.

Настройки приложений:
В разделе applications можно настроить то, как будет отображаться каждое приложение в Discord:

1. process_name - реальное имя процесса (БЕЗ .exe!!!!!);
2. custom_name - кастомное имя процесса. введите то, что вы хотите вывести в Discord;
3. text - основной текст статуса;
4. image - большая иконка;
5. small_image - маленькая иконка;
6. tooltip - текст при наведении на большую иконку;
7. small_text - текст при наведении на маленькую иконку.


Известные баги: 
1. Конфигурационный файл не создается, если код его не нашел;
2. Не работает трей.
