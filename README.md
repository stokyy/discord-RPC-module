# discord-RPC-module

Функционал
Эта программа отслеживает активные окна Windows и отображает информацию о них в Discord через систему Rich Presence (RPC). Основные возможности:

Отслеживание активных приложений:

Автоматически определяет какое приложение сейчас активно;
Показывает название процесса, например, *chrome* (да-да, без .exe);
Определяет PID процесса.

Discord Integration:
Отображает статус в профиле Discord;
Показывает иконки приложений;
Отображает дополнительную информацию, которую вы сами и напишите в cfg, при наведении.

Системный трей:

Работает в фоновом режиме;
Позволяет управлять программой через иконку в трее;
Есть опции скрытия/показа консоли.

Уведомления:

Показывает всплывающие уведомления в Windows (only win 11);
Оповещает о запуске/остановке программы.

Как это работает?
Программа каждые N секунд (указывается в конфиге) проверяет какое окно активно;
Для активного окна определяется процесс и его название;
На основе названия процесса ищется соответствующая конфигурация в config.json;
Если конфигурация найдена - обновляется статус в Discord;
Если не найдена - используется статус по умолчанию (прописано в коде - 72я строчка. используется для process_name`ов, которых нет в cfg).

Конфигурационный файл (config.json)
Файл config.json нужен для настройки программы. Вот зачем он нужен:

Основные настройки:

{
    "application_id": "00000000000000000",
    "debug_mode": false,
    "time": 1,
    "trey": false,
    "applications": {
        "process_name": {"custom_name": "ur_custom_process_name", "text": "ur_custom_text", "image": "ur_custom_img", "small_image": "ur_custom_small_img", "tooltip": "ur_custom_big_img_text", "small_text": "ur_custom_small_img_text"}
    }
}

application_id - ID вашей апликации Discord;
debug_mode - включение режима отладки (вывод в консоль);
time - интервал обновления статуса в секундах;
trey - показывать ли иконку в системном трее.

Настройки приложений:
В разделе applications можно настроить то, как будет отображаться каждое приложение в Discord:

яндекс музыка - реальное имя процесса (БЕЗ .exe!!!!!);
custom_name - кастомное имя процесса. введите то, что вы хотите вывести в Discord;
text - основной текст статуса;
image - большая иконка;
small_image - маленькая иконка;
tooltip - текст при наведении на большую иконку;
small_text - текст при наведении на маленькую иконку.
